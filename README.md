## Overview

YScenes leverages artificial intelligence to provide personalized movie recommendations. Users can search for movies by describing their mood, selecting year ranges, and choosing favorite actors. The platform uses OpenAI's GPT-4o-mini for intelligent recommendations and TMDb API for rich movie metadata, including posters, ratings, and cast information.

### Key Highlights

- **AI-Powered Recommendations**: Uses OpenAI GPT-4o-mini to understand user mood and preferences
- **Smart Duplicate Prevention**: Session-based memory system prevents recommending the same movies
- **Freemium Model**: Free tier with 1 search per session, unlimited searches for paid users
- **Rich Movie Data**: Integrates with TMDb for posters, ratings, cast, and genres
- **Social Sharing**: Share movie recommendations on social media platforms
- **Bookmarking System**: Save favorite movies for later viewing

## Architecture

### Application Flow

```
User Input (Mood/Year/Actor)
    ↓
Frontend (React Components)
    ↓
API Route (/api/recommend)
    ↓
OpenAI API (Generate Recommendations)
    ↓
TMDb API (Enrich with Metadata)
    ↓
Session Memory (Check Duplicates)
    ↓
Return Results to Frontend
    ↓
Display Movies with Rich UI
```

### Data Flow

1. **User Search**: User enters mood, selects year range, optionally selects actor
2. **API Processing**: 
   - Validates input
   - Checks session memory for duplicates
   - Calls OpenAI for recommendations
   - Enriches with TMDb data (posters, ratings, cast)
   - Filters by actor and mood criteria
3. **Response**: Returns 3 movies with full metadata
4. **Display**: Frontend renders movie cards with posters, ratings, descriptions

### Caching Strategy

- **TMDb Cache**: 30-minute cache for movie metadata to reduce API calls
- **AI Mood Suggestions**: 24-hour cache for mood suggestions
- **Session Memory**: In-memory storage for current session to prevent duplicates

## Key Features Explained

### 1. AI-Powered Recommendations

The recommendation system uses OpenAI's GPT-4o-mini model to understand user intent and generate personalized movie suggestions. The system:

- Analyzes mood descriptions (e.g., "scary but heartwarming", "nostalgic for the 90s")
- Considers year range preferences
- Filters by actor when specified
- Avoids duplicates using session memory
- Enriches recommendations with TMDb metadata

**Implementation**: `app/api/recommend/route.ts`

### 2. Session Memory System

Prevents recommending the same movies within a user session:

- Tracks all recommended movies in current session
- Uses localStorage for persistence
- Automatically expires after 24 hours
- Excludes previously recommended titles from new searches

**Implementation**: `hooks/useSessionMemory.ts`

### 3. Search Limit System

Freemium model with search limits:

- **Free Users**: 1 search per session
- **Premium Users**: Unlimited searches
- Tracks search count in localStorage
- Shows paywall when limit reached
- Integrates with subscription system

**Implementation**: `hooks/useSearchLimit.ts`

### 4. Movie Enrichment Pipeline

Enriches AI recommendations with real movie data:

1. Receives movie titles from OpenAI
2. Searches TMDb for movie details
3. Fetches poster images, ratings, cast, genres
4. Validates actor and mood matches
5. Caches results for 30 minutes
6. Returns enriched movie data

**Implementation**: `app/api/recommend/route.ts` (getTMDBData function)

### 5. Subscription System

Full-featured subscription management:

- Stripe integration for payments
- Supabase database for subscription records
- Webhook handling for subscription events
- Automatic activation after payment
- Subscription status checking
- Cancel/renew functionality

**Implementation**: 
- `lib/subscription-service.ts`
- `app/api/webhooks/stripe/route.ts`
- `app/api/subscription/check/route.ts`

## API Routes

### Core Endpoints

#### `POST /api/recommend`
Get movie recommendations based on mood, year range, and actor.

**Request Body**:
```json
{
  "mood": "scary but heartwarming",
  "yearRange": [1990, 2020],
  "actor": "Leonardo DiCaprio",
  "sessionId": "session-id",
  "excludeMovies": [],
  "isFirstRecommendation": true
}
```

**Response**:
```json
{
  "movies": [
    {
      "title": "Movie Title",
      "year": 1994,
      "description": "Movie description",
      "rating_out_of_10": 8.5,
      "poster_url": "https://...",
      "stream_link": "https://..."
    }
  ],
  "sessionId": "session-id",
  "excludedCount": 0
}
```

#### `POST /api/ai-mood-suggestions`
Get AI-generated mood suggestions (cached for 24 hours).

**Response**:
```json
{
  "suggestions": [
    "Need something scary but still heartwarming",
    "Feeling nostalgic for the 90s",
    ...
  ]
}
```

#### `GET /api/subscription/check`
Check user's subscription status.

**Query Parameters**:
- `email`: User's email address

**Response**:
```json
{
  "isVip": false,
  "hasActiveSubscription": false,
  "subscription": null
}
```

#### `POST /api/create-checkout-session`
Create Stripe checkout session for subscription.

**Request Body**:
```json
{
  "priceId": "price_...",
  "userId": "user_...",
  "email": "user@example.com"
}
```

### Additional Endpoints

- `POST /api/bookmarks` - Manage bookmarks
- `POST /api/subscribe` - Email subscription
- `POST /api/share-content` - Share movie recommendations
- `POST /api/post-to-social` - Post to social media
- `GET /api/watch-providers` - Get streaming providers
- `POST /api/webhooks/stripe` - Stripe webhook handler

## Database Schema

### `user_subscriptions` Table

Stores user subscription information:

```sql
CREATE TABLE user_subscriptions (
  id UUID PRIMARY KEY,
  user_id TEXT UNIQUE NOT NULL,        -- Clerk user ID
  email TEXT NOT NULL,
  subscription_status TEXT NOT NULL,   -- 'free', 'active', 'cancelled', 'expired'
  subscription_type TEXT,              -- 'monthly', 'annual', 'lifetime'
  stripe_customer_id TEXT,
  stripe_subscription_id TEXT,
  stripe_price_id TEXT,
  subscription_start_date TIMESTAMPTZ,
  subscription_end_date TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

See `lib/database-schema.sql` for complete schema with indexes and triggers.

## Troubleshooting

### Common Issues

#### 1. OpenAI API Errors

**Problem**: Recommendations not working, OpenAI API errors

**Solutions**:
- Verify `OPENAI_API_KEY` is set correctly
- Check API key has sufficient credits
- Verify API key permissions
- Check rate limits

#### 2. TMDb API Errors

**Problem**: Movie posters or metadata not loading

**Solutions**:
- Verify `TMDB_API_KEY` is set
- Check TMDb API rate limits
- Verify image URLs are accessible
- Check network connectivity

#### 3. Subscription Not Activating

**Problem**: Payment successful but subscription not active

**Solutions**:
- Check Stripe webhook is configured correctly
- Verify webhook secret matches
- Check Supabase database connection
- Review webhook logs in Stripe dashboard
- Check server logs for errors

#### 4. Search Limit Not Working

**Problem**: Free users getting unlimited searches

**Solutions**:
- Verify `useSearchLimit` hook is being used
- Check localStorage is working
- Verify subscription check API is working
- Check user authentication status

#### 5. Duplicate Recommendations

**Problem**: Same movies recommended multiple times

**Solutions**:
- Verify session memory is working
- Check `useSessionMemory` hook
- Verify `excludeMovies` is being passed to API
- Check session expiration logic

1. **Check Browser Console**: Look for JavaScript errors
